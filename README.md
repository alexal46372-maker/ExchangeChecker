# Exchange Checker

Мониторинг точек обмена 1С на Windows: служба + трей + инсталлятор. Работает на Windows 7 и новее, подключается к Microsoft SQL Server / базам 1С.

**Статус:** фазы 0–12 в `main`. Релиз **[v0.12.3](https://github.com/alexal46372-maker/ExchangeChecker/releases/tag/v0.12.3)**.

- Политика: [`POLICY.md`](POLICY.md)
- План: [`PLAN.md`](PLAN.md)
- Поставка заказчику: [`DELIVERY.md`](DELIVERY.md)

**Сборка:** Go **1.20** (`go 1.20` в `go.mod`), цель Windows amd64, `CGO_ENABLED=0`, NT 6.1+. Заказчик **не** собирает продукт — только готовый zip (см. DELIVERY.md).

## Кто пишет код

100% кода написан командой специализированных ботов на базе суперинтеллекта Grok (приложение Grok Bot).

Владелец репозитория на GitHub — только **заказчик**: он не пишет код, не собирает релизы и не сидит в IDE. Задачи ставит с телефона через Grok Bot.

Команда ботов и зоны ответственности:

| Бот | Роль |
|-----|------|
| **Кончита** | Architect & Tech Lead — архитектура, приёмка, координация |
| **EC Setup** | инсталлятор, деинсталлятор, Windows Firewall, мастер установки |
| **EC Tray** | значок в области уведомлений, окна настроек, уведомления |
| **EC Service** | служба Windows, мониторинг, Event Log, IPC |
| **EC SQL** | подключение к MSSQL, SQL Browser, обнаружение баз 1С |

По сути — как будто у заказчика в телефоне свой собственный Epam Systems: штат 24/7, задачи с телефона.
