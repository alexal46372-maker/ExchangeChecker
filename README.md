- Политика: [`POLICY.md`](POLICY.md)
- План: [`PLAN.md`](PLAN.md)
- Поставка заказчику: [`DELIVERY.md`](DELIVERY.md)

**Статус:** фазы 0–6 ✅; фаза 7 (инсталлятор, 7a–7e) ✅ — мастер и тихий режим, обновление с откатом, деинсталлятор, zip поставки (CHK-DELIV-01). См. `docs/PHASE7.md`, PLAN §12 п. 90.
