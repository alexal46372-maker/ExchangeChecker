# Exchange Checker

Мониторинг обменов 1С 8.1 на Windows: служба читает из баз Microsoft SQL Server время последней отправки и приёма сообщений по каждой точке обмена и поднимает тревогу, если обмен задерживается (предупреждение) или остановился либо база недоступна (ошибка). Работает на Windows 7 / Server 2008 R2 (64-бит) и новее. Интерфейс только на русском языке.

**Текущая версия:** **[v0.17.0](https://github.com/alexal46372-maker/ExchangeChecker/releases/tag/v0.17.0)** от 17.11.2026 (фазы 0–17). Что изменилось — [`CHANGELOG.md`](CHANGELOG.md).

## Установка

1. Скачайте `ExchangeChecker-0.17.0.zip` со [страницы релиза](https://github.com/alexal46372-maker/ExchangeChecker/releases/tag/v0.17.0). В архиве один файл — установщик `Exchange Checker 0.17.0.exe`.
2. Запустите его от имени администратора и пройдите мастер: «Приветствие» → «Папка» (по умолчанию `%ProgramFiles%\Exchange Checker`) → «Опции» (ярлык в меню «Пуск», ярлык на рабочем столе, «Запустить службу и запускать автоматически») → «Установка» → «Готово».
3. Тихая установка, ключи командной строки, коды выхода и удаление — в [`DELIVERY.md`](DELIVERY.md). Обновление ставится поверх, настройки сохраняются.

Код не подписан: Windows может показать предупреждение SmartScreen или «Неизвестный издатель».

## Что умеет

- **Служба Windows** `ExchangeChecker` (`ExchangeCheckerSvc.exe`, LocalSystem) опрашивает базы по расписанию (по умолчанию раз в 60 с), сравнивает простой обмена с порогами (по умолчанию 30 мин — предупреждение, 60 мин — ошибка), пишет события в журнал Windows «Приложение» (источник `ExchangeChecker`) и шлёт уведомления в Viber, Telegram и на e-mail.
- **Значок в области уведомлений** (`ExchangeCheckerTray.exe`): цвет стрелок показывает состояние (зелёный — норма, жёлтый — предупреждение, красный — ошибка, серый — нет связи со службой). Левый клик — список баз с точками обмена; галочка у базы включает и выключает её опрос. Правый клик — «Настройки…», «Состояние…», «Проверить сейчас», «Уведомления о просрочке», «Служба», ползунок «Громкость», «Как закрепить значок…», «Сводка…», «О программе», «Выход».
- **Тревога:** окно тревоги поверх всех окон, его нельзя закрыть — только «Подтвердить», «Звук выкл» / «Звук вкл» или свернуть. Значок и облачко у часов мигают (жёлтым или красным ↔ чёрным). При ошибке обмена мигает весь экран; пока окно тревоги свёрнуто, экран не мигает, развернули — мигание возобновляется. После «Подтвердить» мигание гаснет и включается снова на следующей неудачной проверке.
- **Звук:** для уровней «Предупреждение» и «Ошибка» — сигнал «Тон» или звуковой файл (WAV, MP3, WMA, MID); для «Тона» — «Вывод звука»: «Системный динамик» (через службу и драйвер InpOutx64; если динамик недоступен — колонки), «Колонки» или «Динамик и колонки». Файл всегда звучит через колонки. Громкость — общий ползунок в меню значка.
- **Настройки** (меняет только администратор, через запрос UAC): вкладки «Общие настройки» и «Базы данных»; в экспертном режиме ещё «Уведомления Viber», «Уведомления e-mail», «Telegram». Мастер «Добавить базу» находит серверы SQL в сети, базы 1С и таблицы обмена сам; мастер проверяет подключение по шагам и показывает, на каком шаге ошибка. Экспорт и импорт настроек.
- **Установщик** ставит службу, трей, деинсталлятор, драйвер системного динамика (`ExchangeCheckerInpOut`), правило брандмауэра для SQL Browser, ярлыки и запись в «Программы и компоненты».

Подробно — [`DELIVERY.md`](DELIVERY.md) (поставка, установка, журналы, рекомендации по учётной записи SQL) и [`docs/ACCEPTANCE-WIN7.md`](docs/ACCEPTANCE-WIN7.md) (ручная приёмка).
