# Ручная приёмка Exchange Checker на Windows 7 / Server 2008 R2 (черновик)

Документ для человека, который проверяет программу руками на реальной машине. Пишем простыми словами. Всё, что взято из кода или DELIVERY.md, считается фактом; пункты с пометкой **[не проверено]** — предположения, их нужно подтвердить на первой же приёмке.

Что нужно заранее:

- Windows 7 SP1 или Windows Server 2008 R2 (64-бит), учётная запись администратора.
- Zip поставки `ExchangeChecker-<версия>.zip` (внутри один файл `ExchangeChecker-<версия>.exe`). Его собирает workflow `release`. Артефакт GitHub скачивается как **zip в zip**: внешний архив (обёртка GitHub) содержит внутренний zip поставки с тем же именем. Координатор распаковывает внешний архив, сверяет sha256 внутреннего zip с журналом сборки и передаёт для приёмки только внутренний zip. Если вам достался внешний архив — распакуйте его один раз и работайте с внутренним zip. Для сборок по кнопке версия вида `0.0.0-rel.N`, для релиза — `X.Y.Z` (например `0.7.0`).
- Доступ к SQL Server с базой 1С и отдельным логином с ролью `db_datareader` (см. DELIVERY.md).
- Записывайте для каждого шага: «ОК» или что пошло не так + снимок экрана.

Пути, которые понадобятся:

| Что | Где |
|-----|-----|
| Папка программы (по умолчанию) | `%ProgramFiles%\ExchangeChecker` (`ExchangeCheckerSvc.exe`, `ExchangeCheckerTray.exe`, `ExchangeCheckerUninstall.exe`) |
| Данные и настройки | `%ProgramData%\ExchangeChecker` (`settings.json`, `profiles.json`, `secrets.dpapi`), доступ только у SYSTEM и администраторов |
| Журнал службы | `%ProgramData%\ExchangeChecker\logs\exchsvc.log` |
| Журнал установки | `%TEMP%\ExchangeCheckerSetup-ГГГГММДД-ЧЧММСС.log` (или файл из `/LOG=`); путь показан на странице «Готово» |
| Ярлык | меню «Пуск» → «Все программы» → `Exchange Checker` → `Exchange Checker` |
| Служба | `ExchangeChecker` (консоль «Службы», `services.msc`) |
| Event Log | «Просмотр событий» → «Журналы Windows» → «Приложение», источник `ExchangeChecker` |

## 1. Интерактивная установка (RU и EN)

1. Распакуйте zip, запустите `ExchangeChecker-<версия>.exe` (имя совпадает с zip, расширение `.exe`). Должен появиться запрос UAC (программа требует прав администратора). На неподписанный файл Windows может показать предупреждение — см. раздел 11.
2. Язык мастера выбирается по языку Windows; принудительно — ключ `/LANG=ru` или `/LANG=en` (например `ExchangeChecker-<версия>.exe /LANG=en`). Проверьте оба языка: все надписи переведены, текст не обрезан.
3. Страницы мастера: «Приветствие» → «Папка» → «Опции» → «Прогресс» → «Готово». Кнопка «Назад» работает до начала копирования, «Отмена» спрашивает подтверждение.
4. На странице «Опции»: чекбокс ярлыка в меню «Пуск» и чекбокс «Запустить службу и запускать автоматически» (оба включены по умолчанию).
5. Отмена на любой странице до установки → программа ничего не меняет (код выхода 2).

## 2. Кнопка «Обзор…»

1. На странице «Папка» нажмите «Обзор…», выберите обычную папку на диске C: → путь подставляется в поле.
2. Нажмите «Обзор…» и выберите не папку файловой системы (например «Библиотеки» или «Сеть») → должна появиться ошибка «Не удалось получить путь выбранной папки», а не тихая отмена. **[не проверено на Win7 вручную]**
3. «Отмена» в окне выбора → поле не меняется.
4. Сетевой диск или несуществующий диск в поле → мастер не пускает дальше (папка установки должна быть на локальном фиксированном диске).
5. При обновлении поле папки только для чтения.

## 3. Запуск трея на странице «Готово»

1. На «Готово» отмечен чекбокс «Запустить Exchange Checker». Нажмите «Готово» → через несколько секунд в области уведомлений появляется значок.
2. Откройте «Диспетчер задач» → процесс `ExchangeCheckerTray.exe` запущен **от имени вашего пользователя**, не от администратора и не от SYSTEM (трей запускается с правами `explorer.exe`). **[не проверено вручную; в CI не покрыто]**
3. Снимите чекбокс → трей не запускается.
4. При ошибке установки на «Готово» показан текст ошибки и путь к журналу.

## 4. Ярлык в меню «Пуск»

1. «Пуск» → «Все программы» → `Exchange Checker` → `Exchange Checker` запускает трей. Ярлык общий для всех пользователей.
2. Если на «Опциях» сняли галочку ярлыка (или ключ `/NOSHORTCUT`) — ярлыка нет.
3. После удаления программы ярлык и папка `Exchange Checker` в меню исчезают.

## 4a. Правило брандмауэра для SQL Browser (фаза 11) **[проверить вручную на Win7]**

1. После установки (в т.ч. тихой `/S`): «Панель управления» → «Брандмауэр Windows» → «Дополнительные параметры» → «Правила для входящих подключений» → ровно одно правило с именем **`Exchange Checker (SQL Browser)`**.
2. Свойства правила: программа = полный путь к `ExchangeCheckerSvc.exe` в папке установки; протокол UDP; локальные порты — любые (в оснастке часто «Все локальные порты»); удалённые порты — **1434**; удалённые адреса — любые; направление — входящее; действие — разрешить; включено; группа — `Exchange Checker`; профили — **домен и частная** (общественная / Public **не** включена).
3. Повторная установка / обновление поверх: правило по-прежнему **одно** (без дубликатов).
4. После удаления программы правила с этим именем нет.
5. Если служба брандмауэра выключена: установка всё равно завершается успешно; в `%TEMP%\ExchangeCheckerSetup-*.log` есть строка `WARNING` про firewall — это ожидаемо.

## 5. Служба и Event Log

1. `services.msc` → служба `ExchangeChecker`: состояние «Работает», тип запуска «Автоматически (отложенный запуск)», при сбое — перезапуск.
2. Event Log → «Приложение», источник `ExchangeChecker`: при старте службы событие 100. Текст события читается нормально (без фразы «Не найдено описание для события…»).
3. Таблица событий:

| ID | Тип | Когда |
|----|-----|-------|
| 100 | Информация | служба запущена / остановлена |
| 101 | Информация | уровень тревоги снизился |
| 102 | Предупреждение | нет обмена дольше порога предупреждения |
| 103 | Ошибка | нет обмена дольше порога ошибки или база недоступна |
| 104 | Информация | тревога подтверждена из трея |
| 105 | Информация | конфигурация изменена |
| 110 | Ошибка | ошибка конфигурации / внутренняя ошибка |

4. Остановите службу → трей показывает «Служба Exchange Checker не запущена» (серый значок **[цвет не проверен]**). Запустите снова → «Служба работает».

## 6. Настройка подключения к SQL

1. Правый клик по значку трея → «Настройки…» → «Базы данных…» **[точная структура меню не проверена: в каталоге строк есть «Настройки…», «Общие настройки…», «Базы данных…», «Язык (Language)», «О программе», «Выход»]**. Обычный пользователь видит окно «только чтение»; для изменений — кнопка «Изменить (администратор)» (запрос UAC).
2. «Добавить» → заполните: «Название», «Сервер (хост)», «Экземпляр» или «Порт», «База данных», «Аутентификация» (SQL Server — логин и пароль, или Windows — учётная запись службы), «Шифрование».
3. Для SQL Server 2008 R2 без обновлений: основной режим — «Без шифрования» (появится предупреждение, что пароль передаётся почти открытым текстом); при необходимости TLS — «Разрешить TLS 1.0 (SQL Server 2008)».
4. «Проверить подключение» → «успешно» с версией сервера, либо понятная ошибка.
5. «Таблицы обмена…» → «Найти таблицы» → выбрать вариант → «Проверить» → «Применить» → «Сохранить». Строка «Таблицы обмена: настроены».
6. Пароль хранится зашифрованным (`secrets.dpapi`); в `profiles.json` пароля быть не должно.

## 7. Цвета баз в трее

Левый клик по значку — список баз, у каждой цветной квадрат и текст:

| Цвет | Текст | Значение |
|------|-------|----------|
| зелёный | норма | обмен в пределах порогов |
| жёлтый | предупреждение | нет обмена дольше порога предупреждения (по умолчанию 30 мин) |
| красный | ошибка | нет обмена дольше порога ошибки (по умолчанию 60 мин) или база недоступна |
| серый | выключена / ожидание опроса / «последние известные данные» | база отключена, ещё не опрошена или нет свежих данных от службы |

Проверьте: подменю базы показывает точки обмена со временем отправки/приёма (UTC+3); при тревоге появляется окно с кнопкой «Подтвердить» и звук (если включён в «Общих настройках»). Пороги и интервал опроса (по умолчанию 60 с) меняются в «Общих настройках…».

## 8. Обновление поверх старой версии

1. Установите старую версию, настройте базу, убедитесь, что служба работает и трей запущен.
2. Запустите новый `ExchangeChecker-<версия>.exe`. Мастер пишет «Установлена версия X, будет обновлена до Y»; папка не меняется, чекбокс службы недоступен и показывает прежнее состояние.
3. После обновления: трей старой версии закрыт, служба работает, тип запуска тот же, настройки и пароли на месте, в «Программах и компонентах» новая версия.
4. Запуск более старой версии поверх новой без `/ALLOWDOWNGRADE` → отказ сразу на первой странице, «Далее» недоступна; «Отмена» → код 3.
5. Если обновление не удалось, программа откатывается на прежнюю версию (код 1, причина в журнале установки).

## 9. Тихая установка `/S`

Команды (cmd.exe «от имени администратора»; `start /wait` нужен, чтобы дождаться кода выхода):

```
start /wait ExchangeChecker-<версия>.exe /S /LOG=C:\ec-setup.log
echo %ERRORLEVEL%
```

Дополнительные ключи: `/DIR=<папка>`, `/NOSTART` (не запускать службу и не ставить автозапуск), `/NOSHORTCUT`, `/ALLOWDOWNGRADE`, `/LANG=ru|en`. В тихом режиме **никаких окон** и трей после установки не запускается.

Коды выхода: `0` — успех, `1` — ошибка, `2` — отменено, `3` — отказ в понижении версии, `3010` — успех, нужна перезагрузка.

## 10. Удаление (с настройками и без)

1. «Панель управления» → «Программы и компоненты» → Exchange Checker → «Удалить». Окно подтверждения с чекбоксом «Удалить настройки и пароли» (по умолчанию **выключен**).
2. Без чекбокса: служба, ярлык, автозапуск трея, запись в «Программах и компонентах», источник Event Log и файлы программы удалены; трей закрыт во всех сеансах; `%ProgramData%\ExchangeChecker` **остаётся**. Повторная установка подхватывает прежние настройки.
3. С чекбоксом: `%ProgramData%\ExchangeChecker` тоже удалён.
4. Тихо: `"%ProgramFiles%\ExchangeChecker\ExchangeCheckerUninstall.exe" /uninstall /S` (данные остаются) или с `/PURGEDATA` (данные удаляются).
5. Код 3010 — нужна перезагрузка (деинсталлятор удалится после неё); это нормально.

## 11. SmartScreen и антивирус

Код **не подписан**. Возможны: предупреждение «Неизвестный издатель» в UAC, предупреждение SmartScreen/«Защитника» (на Win7 — при скачивании через IE), ложное срабатывание антивируса. Записать: какой антивирус и версия, точный текст, имя файла. Не отключайте антивирус без согласования; при блокировке — сообщите (раздел 12).

## 12. Что прислать, если что-то не так

1. Описание: что делали, что ожидали, что получили; версия из «О программе» или из свойств `ExchangeChecker-<версия>.exe` (вкладка «Подробно»).
2. Код выхода (для `/S`: `echo %ERRORLEVEL%` после `start /wait`).
3. Журнал установки: `%TEMP%\ExchangeCheckerSetup-*.log` или файл из `/LOG=`.
4. Журнал службы: `%ProgramData%\ExchangeChecker\logs\exchsvc.log` (папка доступна только администраторам).
5. Event Log: «Просмотр событий» → «Приложение» → «Фильтр текущего журнала» → источник `ExchangeChecker` → «Сохранить отфильтрованные события как…» (`.evtx`).
6. Снимки экрана окна с ошибкой и, при проблемах с треем, меню трея.
7. **Не присылайте** `secrets.dpapi` и пароли; `profiles.json` можно (паролей в нём нет).
